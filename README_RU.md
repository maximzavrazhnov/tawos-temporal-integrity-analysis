# TAWOS Temporal Integrity Analysis — финальный пакет воспроизводимости

Этот пакет пересобран **из финального комплекта S1–S5, который отправлялся в журнал**, а не из промежуточного notebook.

Главное отличие от предыдущей версии: теперь присутствует исходная SQL-цепочка от TAWOS v1.1 до аналитической когорты и temporal-integrity признаков. SQL восстановлен из истории MySQL Workbench от 21.07.2026 и не реконструирован по памяти.

Состав:

- `S1_SQL/` — 20 SQL-скриптов, provenance и verification outputs;
- `S2_variable_dictionary.xlsx` — словарь и lineage 50 переменных;
- `S3_data/` — финальные производные наборы данных;
- `S4_analysis/` — финальный executed notebook и environment;
- `S5_extended_checks.xlsx` — расширенные проверки устойчивости и переносимости;
- `paper/` — финальные метаданные статьи.

Ключевая выборка: 952 спринта, 15 проектов, 9 репозиториев, 23 661 задача. Сырые TAWOS-данные не включаются.
